# 수정 순서와 전체 목록

각 항목의 원문 발췌·수정안·보존 조건은 ID 링크에 있다. 순서는 아래 다섯 단계로 잡는다. `근거 확인` 항목은 필요한 원시 집계·실행 조건을 확보한 뒤 정정하며, 확인 전 새 수치를 만들어 넣지 않는다.

1. **수치와 정의:** 역할별 지연, 표의 누락 범주, 표본·문항·반복·호출 분모, 검수 세트 구분부터 정리한다.
2. **주장 범위:** 통계적 비열등성과 운영 게이트, 탐색적 관찰과 인과·모델 일반 성질, 지원 범위와 실제 측정을 구분한다.
3. **현재 결론과 변경 이력:** 최신 역할별 구성을 먼저 제시하고 과거 결정을 당시 날짜에 고정한다.
4. **비전공 독해와 시각화:** 용어를 첫 용례에서 풀고 비교 조건·분모·한계를 표·도식과 함께 배치한다.
5. **국소 윤문:** 위의 근거 정정이 끝난 문장에 한해 쉼표·강조 도입·반복 대구를 줄인다. 참가자 발화·코드·표준 약어는 보존한다.

Exp 1의 사실 정정은 앱 정본 → 공개 스냅샷 → 그림 데이터 → 설명 문구 순으로 적용한다. 사전등록은 기존 고정본을 보존하고 해설층 또는 날짜가 있는 별도 개정 기록을 사용한다.

기계 판독/필터링용: [TSV 전체 목록](edit-queue.tsv).
