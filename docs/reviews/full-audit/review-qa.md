# 최종 교차 검토 기록

첫 검토자가 작성한 제안을 다른 검토자가 원문과 다시 대조했다. 8편 담당 검토자는 화면 제안 9건, 모델 후반의 높은 우선순위 22건, 원시 대조 8항목을 확인했다. 모델 전반 담당 검토자는 8편 본문의 높은 우선순위 17건과 화면 제안 9건을 확인했다. 주 검토자는 원장 전체의 범위·인용·참조를 검산하고 주요 수치와 수정안을 다시 대조했다.

다음 7개 항목은 검토 제안 자체의 오류·조건 누락을 수정했다. 연구 원문을 수정한 내역이 아니다.

| 항목 | 발견한 문제 | 최종 보완 |
|---|---|---|
| MD-60 | 제안이 검수 22문장과 초기 30문장 조건을 다시 합침 | 검수 22의 1024·1536·2560과 초기 30의 1536·2560·3072를 분리 |
| MD-39 | 재생성 2인 실행만으로 요약을 고치려 함 | 재생성 0인 추가 실행도 있어 요약이 가리키는 실행을 먼저 확인 |
| MD-46 | 정지 시도 비용이 누락됐다고 포괄적으로 서술 | 원문의 정지 2건 추정 비용 포함을 인정하고 usage 미집계·상한 가정의 한계로 범위를 좁힘 |
| PR-03 | 잠금을 무조건 총점 하락 방지처럼 풀이 | 직전에 인정된 문장이 남아 있는 항목의 판정 하락 방지 조건을 명시 |
| OA-20 | 미래 A/B 설명으로 바꾸면서 현재 관찰의 학습 한계를 지울 가능성 | 현재 관찰의 반복 학습 가능성과 미래 A/B 고려사항을 모두 유지 |
| OA-43 | CV 수치가 실제 적용된 문턱이라고 재단정 | 분류 문턱인지 관측 범위인지 확인한 뒤 서술하도록 변경 |
| PR-01 | 이미 절차임을 밝힌 그림을 완료형 문제의 근거로 지적 | 완료형이 있는 reading.yml 문장으로 근거를 옮기고 그림의 기존 절차 안내 유지 |

검증 명령은 `python3 docs/reviews/full-audit/verify_audit.py`다. 결과는 `validation.json`에 저장된다. 파일별 원문 해시, 모든 비어 있지 않은 행의 단일 포함, 775개 ID, 양방향 참조, 정확한 원문 발췌를 검사한다. 이는 전체 원시 실험의 재실행 검증과 다르다.
