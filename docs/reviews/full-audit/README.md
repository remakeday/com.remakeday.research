이번 검토는 본문 **2,612행**, 화면 관련 **17개 파일**을 포함한다. 문단·표·제목·코드/도식 블록·메타데이터·템플릿 **775개 단위** 모두에 개별 판정과 이유를 남겼다. 누락·중복은 없다. 원문과 사이트 구현은 변경하지 않았다.

## im-not-ai 적용 범위

사용자가 지정한 [humanize-korean 스킬](https://github.com/epoko77-ai/im-not-ai/blob/9747f036cdc28a1a8aea4dc71fef1f7846eb96f7/codex/skills/humanize-korean/SKILL.md)과 같은 커밋의 룰북을 적용했다. 학술 격식·수치·날짜·고유명사·실제 발화·코드·필요한 불확실성은 보존한다. 이번 요청은 검토이므로 본문 윤문을 실행하지 않았다.

직접 연결한 규칙은 C-11(연결어미 뒤 쉼표), I-2(의례적인 강조 도입), C-8(반복되는 대구)다. C-8도 연구상 필요한 구분은 남기는 조건이다. 논문 표·번호·단정하지 않는 문장 자체는 제거 대상이 아니다. **수치·주장·구조 문제는 im-not-ai 패턴으로 포장하지 않고 추가 연구 독해 검토로 분리했다.** 문체 분류는 5개 묶음이며 그중 직접 규칙 ID가 없는 일반 편집 제안도 있다.

자동 지표는 앞선 [지표 실행 기록](../2026-09-18-humanize-korean-metrics.json)에 남겼다. 현재 v2의 report 기준 부재와 essay 대체·placeholder 기준 때문에 AI 작성 확률이나 품질 등급으로 사용하지 않았다. 최종 판단은 원문과 근거를 직접 대조한 이 원장을 기준으로 한다.

## 원문을 잃지 않고 반영하는 경로

Exp 1은 앱 정본 커밋 `1568438`의 공개 가공 결과와 **정확히 일치**한다. 현재 앱 정본에는 그 이후 기록도 있다. 따라서 이 검토의 직접 범위는 공개 스냅샷까지이며 이후 비공개 내용을 자동으로 끌어오지 않았다. [정본 대조 기록](provenance.json).

1. 정본에서 사실·수치·결론 범위를 정정하고 변경 이유를 남긴다. 부족한 근거는 각 제안에 적힌 파일·지표·조건으로 확인한다.
2. 공개 가공 규칙을 적용해 스냅샷을 다시 생성하고 그림 데이터와 출처 해시를 갱신한다.
3. 요약과 본문이 같은 결론·시점·분모를 가리키게 맞춘다. 긴 기록은 탐색 구조로 정리하고 삭제하지 않는다.
4. 용어와 문장을 다듬은 뒤 원문 수치·고유명사·인용·미실행 상태가 보존됐는지 비교한다.

원시 검증은 로컬 결과 집계와 연결 보고서·측정 스크립트 대조까지다. DB를 다시 조회하거나 기존 6판의 원시 이벤트를 전수 검증하지 않았고, 모든 비용·라이선스·인과 설명을 확정한 것도 아니다. 그 항목들은 필요한 자료를 명시한 상태로 남겼다. 검토 문서는 사이트 빌드에서 제외되는 `docs/reviews/`에 저장했으며 연구 페이지는 아직 변경하지 않았다.
