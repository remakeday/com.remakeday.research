# 사람 관찰·사전등록·한계·연구 기록 검토

검토 기준: 사용자 지정 `epoko77-ai/im-not-ai`의 Codex `humanize-korean/SKILL.md`, `quick-rules.md`와 필요한 taxonomy 항목. 기준 체크아웃은 `ff6afd0`이다. 원문을 수정하지 않은 검토이며, 글의 작성 주체를 판정하지 않는다. 아래 **추가 검토** 항목은 humanize 규칙으로 잡힌 문체 문제가 아니라 독자 이해 또는 근거 범위 문제다. 연구 장르의 영어 약어·측정값·인용·필요한 유보는 제거 대상으로 보지 않았다.

## 우선 검토할 8건

### 1. 검수 22문장 결과와 미검수 30문장 반복 실험이 같은 결과처럼 이어진다

- 우선순위: P1 — 근거 범위. **추가 검토: EVIDENCE-COHORT**; humanize ID 없음.
- 위치: `lab-notes.md:17–20`.
- 원문: “골든은 초안 30문장을 Scenario Director가 검수해 22문장(뜻이 다른 8문장 제외). … top-3는 임베딩 전 셀 1.000. 반복 n=3 적중률·오답 집합 완전 동일(결정론).”
- 근거 대조: `experiments/model-selection.md:1680`은 1차 30문장이 미검수라고 구분하고, `:1706`은 **“반복 n=3(1차 골든, 조용한 GPU)”**라고 명시한다. 날짜별 요약에서는 이 연결 조건이 빠져 검수 22문장을 세 번 반복한 것으로 읽힌다.
- 보수적 수정 예시: 마지막 문장만 “별도로, 미검수 1차 골든 30문장의 반복 n=3에서는 적중률·오답 집합이 완전히 같았다(결정론).”로 범위를 명시한다. 앞의 검수 세트 적중률은 그대로 둔다.
- 처리 경계: 스타일 치환으로 해결할 사항이 아니다. 정본의 세트 정의를 근거로 정정해야 하며, 새 수치를 추정하거나 다시 계산하지 않는다.

### 2. 한계 페이지의 ‘합산하지 않는다’와 실제 기존 집계의 예외가 충돌한다

- 우선순위: P1 — 근거 범위. **추가 검토: EVIDENCE-CONDITION**; humanize ID 없음.
- 위치: `limitations.md:34–35`.
- 원문: “관찰 기간 중 실험기구(모델·프롬프트·채점기)가 수정되었다. 수정 전후 세션은 합산하지 않고 각 세션에 당시 기구 버전을 병기한다.”
- 근거 대조: `experiments/human-observations.md:72–73`은 “위 집계는 전 기간 합산이므로 경향 주장에 쓰지 않고, 버전별 분리 집계를 후속으로 남긴다.”고 기록한다. `_data/reading.yml:93`은 이미 이 예외를 정확하게 안내한다.
- 보수적 수정 예시: 분리 원칙은 유지하면서 바로 뒤에 “다만 Exp 2의 기존 집계에는 수정 전후 세션이 섞여 있다. 이 집계는 경향 주장에 쓰지 않으며 버전별 분리 집계는 후속 작업으로 남아 있다.”를 붙인다. 문두도 완료 사실처럼 읽히지 않도록 “수정 전후 세션은 합산하지 않는 것을 원칙으로 하며…”로 조정할 수 있다.
- 처리 경계: 원문이 말한 원칙과 현재 집계 상태를 함께 설명하는 정정이다. 합산표 자체나 수치를 윤문 과정에서 바꾸지 않는다.

### 3. 현재 관찰 결과가 아닌 ‘서술 예시’를 더 눈에 띄게 표시할 필요가 있다

- 우선순위: P2 — 결과와 예시 구분. **추가 검토: EVIDENCE-EXAMPLE**; humanize ID 없음.
- 위치: `experiments/human-observations.md:166–167`.
- 원문: “\"직접 작성이 더 효과적이었다\" 같은 인과 표현은 쓰지 않는다. \"직접 작성 선택과 이후 이해도 상승 사이에 더 큰 연관성이 관찰되었다\"처럼 쓴다.”
- 판단: “처럼 쓴다”가 예시임을 알리므로 이를 잘못된 결과 주장이라고 단정하지는 않는다. 다만 독자가 마지막 문장을 발췌하면 실제 분석에서 더 큰 연관성을 발견한 것으로 읽힐 수 있다. 이 페이지에는 그 비교를 입증하는 분석 결과가 제시돼 있지 않다.
- 보수적 수정 예시: 문구는 유지하고 둘째 문장 앞에 “관찰 결과가 뒷받침될 때의 **서술 예시이며, 현재 결과를 뜻하지 않는다:**”라는 표지를 둔다.
- 처리 경계: 인과 표현 금지 자체는 필수 연구 원칙이며 삭제하지 않는다.

### 4. 쉬운 요약에 먼저 나오는 ‘단조 잠금’이 설명 없이 독자를 막는다

- 우선순위: P2 — 첫 등장 설명. **추가 검토: READABILITY-TERM**; B-2에 해당한다고 보지 않음(실제 기술 개념이므로 광고성 용어가 아님).
- 위치: `_data/reading.yml:65`; `_includes/research/figures/human-observations.html:29,39,56`; 설명의 원문 근거는 `experiments/human-observations.md:148–149`.
- 원문: “후속 사례의 같은 제출문과 단조 잠금 구간은 학습이나 채점 안정성의 증거가 아닙니다.”
- 판단: 그림 아래에서는 점수 하락 방지라고 설명하지만, 요약과 그림 내부의 첫 등장에서는 ‘단조 잠금’을 이해해야 경고의 의미를 읽을 수 있다.
- 보수적 수정 예시: “후속 사례에는 같은 제출문에 더 낮은 점수를 주지 않는 처리인 **단조 잠금**이 적용됐습니다. 같은 제출문과 단조 잠금 구간은 학습이나 채점 안정성의 증거가 아닙니다.” 그림 내부는 공간을 고려해 “같은 글 · 점수 하락 방지”와 캡션의 기술 명칭을 함께 쓸 수 있다.
- 처리 경계: 이 설명은 원문에 있는 작동 원리를 푸는 것이며, 단조 잠금의 범위를 다른 상황까지 넓히면 안 된다. 필요한 경고의 강도는 유지한다.

### 5. 날짜별 기록은 분야별 개발자에게 필요한 설명까지 압축돼 있다

- 우선순위: P2 — 문장 압축·전문 용어. **추가 검토: READABILITY-DENSITY**; B-2/C-2로 일괄 분류하지 않음.
- 위치: `lab-notes.md:15–20`, `:25–28`, `:71–75`.
- 대표 원문: “신의 개입에서 직접 쓴 규칙이 거부됐을 때 주는 대안 3개의 순위 — 플레이어가 고르는 추천이라 틀려도 채점·게이트에 무해, 실패 시 어간 겹침 폴백.”
- 판단: ‘신의 개입’, ‘게이트’, ‘어간 겹침 폴백’의 역할과 문장의 주어를 독자가 복원해야 한다. 날짜별 불릿 자체는 연구 노트 장르에 맞으므로 산문으로 전부 바꿀 이유는 없다.
- 보수적 수정 예시: “신의 개입에서 직접 쓴 규칙이 거부되면 대안 3개의 순위를 매긴다. 플레이어가 고르는 추천이므로 순위가 틀려도 채점·게이트에는 영향을 주지 않는다. 순위 계산이 실패하면 기존 어간 겹침 방식으로 폴백한다.” 첫 등장 ‘게이트’에는 기존 통과 기준 용어집 링크를 제공한다.
- 처리 경계: 용어를 기계적으로 번역하거나 `top-1`, `n=3`, 모델명, 차원·메모리 수치를 바꾸지 않는다. 한 불릿 안에서 문장만 나누어도 개선된다.

### 6. 사전등록은 핵심 A/B 외 연구 질문·보조 측정값을 영어로만 제공한다

- 우선순위: P2 — 언어 접근성. **추가 검토: READABILITY-PROTOCOL**; B-1/B-2와 구별함.
- 위치: `prereg.md:18–31`, `:45–58`, `:90–105`; 관련 독자 안내는 `_data/reading.yml:69–81`, `_includes/research/figures/prereg-ab.html:3–18`.
- 원문 예: “How are different intervention strategies associated with subsequent understanding and side-effect recognition?” / “Δ Understanding Score · Side-effect Recognition · Custom Rule Selection · Cause-chain Question Hit Rate”.
- 판단: 현재 요약과 그림은 주 실험의 이유 유무·수용률·미실행을 잘 풀지만, RQ3나 보조 결과값과 ‘극성 쌍’을 읽을 안내는 부족하다. 영어 연구 용어가 있다는 이유로 삭제할 대상은 아니다.
- 보수적 **외부 안내** 예시: 고정 원문 위 안내에 “RQ3는 개입 전략별로 이후 이해도와 부작용 인지가 어떤 관계를 보이는지 묻습니다.”를 추가하고, 원문 `Δ Understanding Score` 옆으로 이동할 수 있는 “이해도 점수 변화” 안내를 제공한다. 측정 방법·척도·판정 문턱은 임의로 보충하지 않는다.
- 처리 경계: **사전등록 원문은 고정 기록이므로 수정하지 않는다.** 독자 안내·용어 해설을 고정 프로토콜 밖에 둔다. `NOT RUN`과 “0%나 효과 없음이 아님” 설명도 유지한다.

### 7. ‘관찰 점수’보다 측정 대상을 드러내는 표제가 정확하다

- 우선순위: P3 — 그림 명칭. **추가 검토: READABILITY-MEASURE**; humanize ID 없음.
- 위치: `_includes/research/figures/human-observations.html:26,28`; 원문 표 `experiments/human-observations.md:117`은 “총점”이다.
- 원문: “Tester 6의 회차별 관찰 점수”, “Tester 6의 …회차 관찰 점수 선 그래프”.
- 판단: ‘관찰 점수’는 관찰자가 사람의 능력을 평가한 별도 척도처럼 읽힐 여지가 있다. 현재 그림의 정확한 값 목록(:51)과 캡션(:58)은 이미 ‘총점’이라고 쓴다.
- 보수적 수정 예시: “Tester 6의 회차별 게임 총점” / “Tester 6의 …회차 게임 총점 선 그래프”.
- 처리 경계: 총점을 이해도나 학습 효과로 재명명하지 않는다. 값·축·출처·해석 경고는 모두 그대로 둔다.

### 8. 연결어미 뒤 쉼표는 작은 범위에서 기계적으로 덜어낼 수 있다

- 우선순위: P3 — 국소 윤문. **humanize C-11**(연결어미 직후 쉼표).
- 위치: `_data/reading.yml:59,93`; `experiments/human-observations.md:21,48,73,145`.
- 대표 원문: “분리한 사람 세션에서 규칙 선택의 출처를 세었고, 이후 다른 기구 버전의 완주 판은 별도 사례로 남겼습니다.”
- 보수적 수정 예시: “분리한 사람 세션에서 규칙 선택의 출처를 세었고 이후 다른 기구 버전의 완주 판은 별도 사례로 남겼습니다.”
- 다른 예: “미해결이며, …행동 결론으로 쓰지 않는다.” → “미해결이며 …행동 결론으로 쓰지 않는다.”
- 처리 경계: 각각의 규칙 일치 사례만 제안한다. 분량이 긴 연구 노트 전체의 쉼표를 일괄 제거하거나 이 빈도로 작성자를 추정하지 않는다. 실제 발화 인용·코드의 쉼표는 대상이 아니다.

## 유지할 표현과 구조

- `experiments/human-observations.md:11–15,67–73`: 확정·유력의 구분, 선택 편향, 판정 요동, 기구 버전 혼재는 결론 강도를 제한하는 근거다. G-1/G-2의 ‘과도한 완곡’으로 처리하면 안 된다.
- `experiments/human-observations.md:139–151`: 추천 질과 직접 작성 사이의 **가능성**, N=1, 부작용 인지 미해결, 단조 잠금 경고는 결과를 정확하게 읽는 데 필요하다. 표현을 줄이더라도 확신도·극성·인과 경계는 보존해야 한다.
- `prereg.md:11–13,112–129`: 미실행, 설계 변경 시 새 실험, 무작위 배정 축 외 인과 금지, LLM을 검증된 인간 대체로 보지 않는 원칙은 핵심 연구 내용이다. 반복돼 보여도 삭제하지 않는다.
- `limitations.md:39–53`: 관찰 구성과 서빙 구성 구분, 19/20(95%), 비용 추정과 실측 토큰의 구별은 그대로 둔다.
- `_includes/research/figures/human-observations.html:17–19,56–58`: 선택 건수와 단일 사례를 분리하고 각각 출처·해석 한계를 붙인 구성이 적절하다.
- `_includes/research/figures/prereg-ab.html:14–18`: 결과 막대 없이 NOT RUN을 표시하는 방식과 ‘0%가 아님’ 설명이 적절하다. 영어 레이블은 한국어가 함께 있어 핵심 이해를 막지 않는다.
- `lab-notes.md`의 날짜별 불릿, 모델명·런 ID·지표·실패 기록은 연구 노트에 맞다. C-2/C-9를 이유로 나열이나 숫자를 일괄 산문으로 바꾸지 않는다.
- “~인과가 아니라 연관성”, “채점기 안정성의 증거로 쓰지 않는다” 같은 대구는 문체 장식이 아니라 해석 경계다. C-8의 단순 출현 횟수만으로 없애지 않는다.
